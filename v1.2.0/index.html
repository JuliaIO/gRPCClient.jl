gRPCClient.jl

A production grade gRPC client for Julia

Built on libcurl, emphasizing performance and reliability.

Get started Guide View on GitHub
🔁

Unary and streaming RPCs

Unary, client streaming, server streaming and bidirectional streaming, each callable synchronously or asynchronously.
🧩

Generated service modules

protojl turns every service into a module of RPC functions with typed signatures and docstrings.
✅

Julia 1.10 and newer

Tested on Linux, Windows and macOS, with workarounds for the libcurl bugs in the versions bundled with Julia 1.10 and 1.11.

🧵

Thread safe

Start and drive calls from any task or thread.
⚡

Built for throughput

Profiled, benchmarked and optimized to minimize allocations and maximize throughput.
📦

Partial decoding

Send and receive raw encoded buffers when you only need part of a message.

Planned features

The client is missing a few features which will be added over time if there is sufficient interest:

  • OAuth2
  • Compression
